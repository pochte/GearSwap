This is an expanded version of Sel's Cheatsheet.

Install Instructions: Install All files found in this folder. 

Overwrite his files with mine, since my files expand on his framework. Not all Jobs are completed currently, and as such, I highly suggest using his framework for those until I do complete them.

### First-Time Setup

**1. Run `rename.bat` first.**

**2. Open `user-globals.lua`.**

Set the character name you want these custom files enabled for:

local Character = 'Ullona'

Change `Ullona` to your character name.
`user-globals.lua` acts as the character handler. Your normal job files (`BLM.lua`, `RDM.lua`, `GEO.lua`, etc.) remain in the main `GearSwap\data` folder.
Character-specific gear and custom files are kept in the character's folder.
If the logged-in character does not match the name set in `user-globals.lua`, the custom files simply exit without loading.

To make use of other types of GearSwap files along with mine, place them in the common folder, and make sure to name them `Character_Job.lua`.

### Additions on top of Sel's Cheatsheet
Everything below is stuff added on top of Sel's base framework -- new commands, changed keybinds, and automatic behaviors that just happen without you needing to press anything.

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ New Commands ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
**Smart Cure** = Automatically picks a Cure tier based on missing HP instead of you eyeballing it.
Native on WHM/RDM/BLM; also works on GEO/SCH/SMN through whatever Cure access your subjob provides.
No target given = current target, or yourself if nothing is targeted.
Can also target by name or mob/player ID.

**Macro:**
/console gs c smartcure


**Smart Waltz** = Automatically chooses the appropriate Curing Waltz tier based on missing HP.
Requires /DNC as your subjob. If /DNC is not equipped, it aborts cleanly with a chat message.
No argument:
- Below 75% HP = automatically Waltzes yourself with the appropriate tier.
- At or above 75% HP = falls back to a `<st>` click-prompt for yourself or an ally, using the strongest tier you can afford.
**Smart Na** = Automatically determines which status-removal spell is needed.
Cast a Barspell corresponding to the expected debuff, and Smart Na will detect it and use the appropriate -na spell to remove it.
If no matching debuff is detected, it defaults to **Cursna**.
**Macro:** 
/console gs c smartna


~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ Changed Keybinds ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

These three used to be bare F-keys with no modifier at all -- way too easy to bump by accident mid-fight. Same commands as before, just moved off the naked key.

**[Ctrl+F7]** (was bare F7) = Cycle through weapon sets.

**Macro:**
```text
/console gs c cycle Weapons
```

**[Ctrl+Alt+F9]** (was bare F9) = Change offense mode.

**Macro:**
```text
/console gs c cycle OffenseMode
```

**[Ctrl+Alt+F10]** (was bare F10) = Cycle Defense Mode (None -> Physical -> Magical -> Resist -> loop).

**Macro:**
```text
/console gs c cycle DefenseMode
```

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ Automatic Behaviors ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Nothing to press for these -- they just happen.

**Auto-Recover MP** = Global across every mage job (WHM/RDM/BLM/GEO/SCH, and SMN whenever no avatar is out).

Automatically equips MP-recovery gear any time MP drops below 75%.

This replaces the old RecoverMode modal. There is no longer a 35%/60%/Always/Never toggle or per-job @F10 RecoverMode bind.

**Auto Haste-Tier Melee Gear** = Global.

Watches for Haste, March, Mighty Guard, Embrava, Geo-Haste, Indi-Haste, and Haste Samba stacking.

Automatically swaps melee gear into the appropriate `Haste_15`, `Haste_30`, or `MaxHaste` group whenever haste buffs land or wear off.

Currently only THF has real gear filled in for these three tiers. Other jobs need `sets.engaged.Haste_15`, `sets.engaged.Haste_30`, and `sets.engaged.MaxHaste` populated in their own gear file before this does anything visible for them.

**Assassin's Charge Auto-JA (THF only)** = Automatically uses Assassin's Charge before a weaponskill if it is not already active and is off cooldown.

This makes Triple Attack apply to the weaponskill's first hit instead of potentially being consumed by a random melee swing.

**Extended Treasure Hunter Credit (THF only)** = Provoke, Animated Flourish, and, when subbing /DNC, Quick Step, Box Step, Stutter Step, Desperate Flourish, and Violent Flourish now count toward maintaining Treasure Hunter credit.

This extends the existing tagging behavior beyond ranged attacks and Aeolian Edge.

Thank you Norrec for this bit!

**Luopan HP Boost on Summon (GEO only)** = Life Cycle automatically equips HP+ gear, including Bagua Galero, at the exact moment Life Cycle resolves.

Luopan maximum HP is calculated from your gear at the time of summoning, so the gear must be equipped during the actual summon.

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ WHM Elemental Wheel ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The WHM elemental wheel from Sel's base framework has been re-enabled.

The elemental wheel is used to control **weather and Barspells**.

A system message displays what each part of the elemental wheel controls.

**[Ctrl+A]** = BarElement

**[Alt+A]** = BarStatusEffect

Light and Dark do not have a single elemental Barspell, so their wheel positions contain **two BarStatusEffect spells** instead.

The elemental wheel therefore provides quick access to the appropriate weather and Barspell options without having to manually select each spell.

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ Macros and More ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

**[Ctrl+F8]** = Toggle auto-stun mode.

Automatically attempts to stun abilities listed in your `Windower4\addons\GearSwap\libs\Sel-MonsterAbilities.lua` file.

**Macro:**
```text
/console gs c toggle AutoStunMode
```

**[Alt+F8]** = Toggle auto-defense mode.

Automatically attempts to swap into and out of defensive sets for specific monster abilities listed in your `Name-Globals` file.

**Macro:**
```text
/console gs c toggle AutoDefenseMode
```

**[Win+F8]** = Turns on auto nuking on supported jobs.

**Macro:**
```text
/console gs c toggle AutoNukeMode
```

**[F9]** = Change offense mode.

Usually Engaged and accuracy modes.

Fodder/Trash Mob sets generally use more Dual Wield and Multiattack because they do not need as much Accuracy or Attack.

**Macro:**
```text
/console gs c cycle OffenseMode
```

**[Ctrl+F9]** = Change hybrid engaged mode.

Usually defensive modes such as PDT or Evasion.

Combines with OffenseMode to create an engaged set containing both options if configured in GearSwap.

**Macro:**
```text
/console gs c cycle HybridMode
```

**[Alt+F9]** = Change weaponskill mode.

Usually accuracy sets based on the target.

**Macro:**
```text
/console gs c cycle WeaponskillMode
```

**[Win+F9]** = Change ranged mode.

Usually accuracy sets based on the target's evasion.

This does not affect ranged weaponskills; those use WeaponskillMode.

**Macro:**
```text
/console gs c cycle RangedMode
```

**[F10]** = Lock a Physical Defense set.

Only changes some gear for spells and abilities.

Generally an "OH Shit Button" for responding to physical abilities.

**Macro:**
```text
/console gs c set DefenseMode Physical
```

**[Ctrl+F10]** = Change the current Physical Defense set.

Common examples include PDT, Evasion, and PDTTwilight.

**Macro:**
```text
/console gs c cycle PhysicalDefenseMode
```

**[Alt+F10]** = Toggle kiting mode.

Keeps movement-speed gear equipped during idle/defensive sets and should also prevent movement-speed-reducing gear from replacing it.

**[Win+F7]** = Automatic ranged attacks.

To change the weaponskill, use `//gs c autows` while RngHelper is active.

Use `//gs c toggle autowsmode` to enable or disable automatic weaponskills during RngHelper.

**Macro:**
```text
/console gs c toggle RngHelper
```

**[Win+F10]** = Toggle job-specific modes.

These vary by job. Some examples:

```text
THF:    /console gs c toggle AmbushMode
        Equips Ambush gear on TP and non-SA/TA WS.

BLU:    /console gs c toggle LearningMode
        Locks learning gear in at all times.

PLD/RUN: /console gs c toggle TankAutoDefense
          Maintains PDT during AutoDefense instead of leaving defense altogether.

BRD:    /console gs c cycle ExtraSongsMode
        Your next song plays as a dummy song. [Ctrl+~]

BLM:    /console gs c cycle RecoverMode
        Nukes in gear that converts elemental damage to MP.

BLM2:   /console gs c cycle MagicBurstMode
        Single makes your next spell burst.
        Lock keeps bursting until toggled again. [Win+~]
```

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ Non F-Key Combinations ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

**[Ctrl+T]** = Change Treasure Hunter mode.

- Tag: Equips TH gear for one hit.
- Fulltime: Keeps TH gear equipped.
- SATA: Uses TH gear for Sneak/Trick Attack.

**Macro:**

```text
/console gs c cycle TreasureMode
```

**[Alt+T]** = Target the current battle target.

**Macro:**
```text
/target <bt>
```

**[Ctrl+O]** = Toggle Fillmode.

Allows you to see through walls, ceilings, and floors.

**Macro:**
```text
/console fillmode
```

**[Alt+P]** = Equip Cure-Potency-Received gear.

Used to maximize incoming cures reactively.

**Macro:**
```text
/console gs equip sets.Self_Healing
```

**[Win+P]** = Equip Sheltered equipment.

Used to maximize incoming Protect and Shell effects.

**Macro:**
```text
/console gs equip sets.Sheltered
```

**[Win+Pause/Break]** = Toggle AutoBuffMode.

Automatically buffs according to the job's configuration.

**Macro:**
```text
/console gs c toggle AutoBuffMode
```

Subcommands can change the default options:

```text
//gs c autoindi Focus
//gs c autogeo Malaise
```

```lua

```

**[Ctrl+Win+Alt+F7]** = Toggle AutoWSMode.

Automatically uses weaponskills.

**Macro:**
```text
/console gs c toggle AutoWSMode
```

Subcommands can change the options:

```text
//gs c autows Savage Blade
//gs c autows tp 1250
```

Defaults can also be changed in the `job_character_gear.lua` file:

```lua
autows = 'Savage Blade'
autowstp = 1250
```

**[Alt+F8]** = Toggle AutoDefenseMode.

Automatically pushes the F10-F12 defense commands based on configured monster abilities.


~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ Addon and Plugin Related Combinations ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

These are configured in `init`, but can be moved elsewhere.

**[Ctrl+Alt+Win+?]** = Load or reload an addon/plugin.

The `?` key depends on the addon/plugin.

**[Win+?]** = Unload an addon/plugin.

GearSwap is the exception.

```text
[G]     = Anchor
          Prevents knockback from monster TP moves.

[Q]     = AllSeeingEye
          Allows you to see things usually invisible to players.

[O]     = Dressup
          Prevents players from blinking with the proper setup.

[T]     = Zonetimer
          Tracks time spent in a zone or since loading the timer.

[I]     = Gametime
          Displays the day of the week and current time.

[R]     = Treasury
          Automatically lots, passes, or drops configured items.

[F12]   = GearSwap
          Reloads GearSwap to reset modes or apply changes.
```

My `scripts\init.txt` loads Request, an addon that can be used to answer player requests with the Shortcuts addon.

It also loads several other addons that I've written or found from other sources.

Non-official addons mentioned here can be downloaded from:
https://www.dropbox.com/sh/qz5rb5je202cbu3/AAAxozfBv_8agarM0NCnPTiZa?dl=0

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ Item Handling ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Items are handled with the `useitem` command:

```text
gs c useitem slot item name
```

For example:

```lua
windower.send_command('bind ^h gs c useitem ring2 Warp Ring')
```

As a macro:

```text
/console gs c useitem ring2 Warp Ring
```

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ Capacity Mode ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

**[Ctrl+Z]** = Capacity Mode.

Automatically uses capacity items and keeps the Capacity Cape equipped.

For this to work correctly, capacity items should be kept in your inventory or satchel rather than wardrobe locations.

Items in the wardrobe may report incorrect remaining-use times to the function that checks them.

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ Auto Commands ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Some job GearSwap files have automatic functions such as:

- Auto-enmity for PLD
- Auto-buffing
- Auto-nuking
- Auto-tanking
- Auto-ready
- Auto-subjob modes

These are generally controlled with `Win+F8` or `Win+Pause/Break`.

Most can be configured in `Character-Globals.lua`.

**Macros:**
```text
/console gs c toggle AutoNukeMode
/console gs c toggle AutoBuffMode
/console gs c toggle AutoTankMode
/console gs c toggle AutoReadyMode
/console gs c toggle AutoSubMode
```

Some automatic-mode choices can be reset with commands such as:

```text
//gs c autonuke fire5
//gs c autows Savage Blade
//gs c autows tp 1250
//gs c autofood Soy Ramen
```

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ Export Command ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Export your current gear for editing in GearSwap:

```text
//gs export lua
```

or:

```text
/console gs export lua
```

This creates a file in `GearSwap\Data\Export` containing your current equipment.

The exported file is useful for obtaining exact item names and augment information for use in job-specific gear files or shared `items.lua` files.

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ Elemental Handling Commands ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Mage jobs can use the following elemental commands.

**Cycle ElementalMode:**

```text
/console gs c cycle ElementalMode
```

**Elemental commands:**

```text
/console gs c elemental [COMMAND]
```

Available commands:

```text
nuke            = Highest available nuke
smallnuke       = Tier 2 or Tier 1 nuke
helix           = Elemental Helix
weather         = Scholar Weather
skillchain1     = Tier 1 skillchain
skillchain2     = Tier 2 skillchain
skillchain3     = Fire-only Liquefaction > Fusion
skillchain4     = 4-step skillchain for Perfidion
skillchain6     = 6-step skillchain for Pluton
wsskillchain    = Start skillchain with WS and finish with spell
endskillchain   = End a skillchain with the current element
tier1           = Tier 1 spell of the current element
tier2           = Tier 2 spell of the current element
tier3           = Tier 3 spell of the current element
tier4           = Tier 4 spell of the current element
tier5           = Tier 5 spell of the current element
tier6           = Tier 6 spell of the current element
aga             = Highest available -aga/-aja spell
aga1            = Tier 1 -aga
aga2            = Tier 2 -aga
aga3            = Tier 3 -aga
aja             = -aja spell
ancientmagic    = Burst/Flood/etc.
ancientmagic2   = Burst II/Flood II/etc.
enfeeble        = Elemental enfeeble
bardsong        = Elemental Threnody for proc
ara             = Highest available -ra spell
ara1            = Tier 1 -ra
ara2            = Tier 2 -ra
ara3            = Tier 3 -ra
```

**Skillchain6 requirements:**

Requires a Strategem and all 5 Strategem charges available at the start.

**WSSkillchain** attempts to conserve Strategems by starting the skillchain with a weaponskill and finishing it with a spell.
